Crayon Red
#
If you want to use the alternative lighter images, proceed as follows (images created by Talk19Zehn) from the contrib imgs_alternate_webp directory:

Load the graphics into the theme / images directory of this style.
#

##
stylesheet.css

find: background-image: url("./images/hgbodyred.webp");

body {
	background-image: url("./images/hgbodyred.webp");
	background-position: left top;
	background-repeat: repeat-x;
	padding: 40px 0;
}

change to: background-image: url("./images/hgbodyredfirst.webp");

body {
	background-image: url("./images/hgbodyredfirst.webp");
	background-position: left top;
	background-repeat: repeat-x;
	padding: 40px 0;
}

find: background-image: url("./images/bgheaderbarimagered.webp");

.headerbar {
